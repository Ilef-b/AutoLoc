# \# AutoLoc

# 

# Plateforme de gestion de location de véhicules multi-agences.

# 

# \## Objectifs du projet

# AutoLoc permet la gestion des réservations, véhicules, agences et clients

# pour une entreprise de location de véhicules multi-agences.

# 

# \## Acteurs identifiés

# \- \*\*Client\*\* : consulte les véhicules disponibles, effectue des réservations

# \- \*\*Agent d'agence\*\* : gère les réservations et l'état des véhicules au quotidien

# \- \*\*Responsable d'agence\*\* : supervise l'activité de son agence

# \- \*\*Administrateur\*\* : gère l'ensemble de la plateforme et des agences

# 

# \## Stack technique

# Java 17, Spring Boot, Spring Data JPA, MySQL, Maven
